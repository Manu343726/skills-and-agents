# Go quality

## Packages

- **A package is a responsibility**, not a layer. `internal/roms` parses ROMs; it does not also open
  sockets. When a package needs the word "and" to describe it, it is two.
- **`internal/` for what is not an API**, `cmd/<name>` for a binary, and nothing at the module root
  but the wiring.
- **No import cycles, no `utils`.** A helper belongs where its second caller is.
- **The package name is the first word of the sentence**: `roms.Parse`, not `roms.ParseRom`.

## Errors

- **Return them; do not log and return.** A function that logs an error and returns nil has hidden it.
- **Wrap with `%w` and context**: `fmt.Errorf("load rom %q: %w", path, err)`. The caller decides what
  to do; the wrapper decides what it means.
- **Sentinel or typed errors for what a caller branches on**, strings for what a human reads.
- **`errors.Is`/`errors.As`, never a string comparison.**
- **Panic is for programmer error only**, and it is documented. An untrusted input never causes one.

## Context

- **`ctx` is the first parameter of anything that can block or cross a boundary** — I/O, a request, a
  call to another service.
- **It is propagated, never stored.** A struct field holding a `context.Context` is a bug.
- **Cancellation is honoured**: a loop that cannot be cancelled is a leak with a schedule.
- **A timeout belongs to the caller**, not to a hardcoded constant deep inside.

## Concurrency

- **Every goroutine has an owner and an exit.** Whoever starts it knows how it stops; `errgroup` or a
  `WaitGroup` and a `ctx` are the two honest ways.
- **No unbounded goroutines per item.** A pool, a semaphore, or a measured decision.
- **Channels carry data, mutexes guard state.** Do not use one to avoid thinking about the other.
- **Send on a channel you own, close on the sender only**, and never close one somebody may write to.
- **`-race` on every test run**, not as a separate gate somebody forgets.

## State and data

- **No package-level mutable state.** A package-level var that is written at runtime is a race with a
  nicer name; pass it or own it in a struct.
- **Copy small values, pass pointers to big ones**, and be explicit when a value must be immutable.
- **`time.Time` in UTC, formatted at the edge**; durations typed (`time.Duration`), not bare ints.
- **`json`/`yaml` tags are an API**: adding a field is additive, renaming one is a break.

## Tests

- **Table-driven** for anything with cases, with `t.Run(name)` per case so a failure names itself.
- **`t.Parallel()` where the test is independent**, and nothing shared between cases.
- **A fake at the boundary, the real thing inside it**: the codec, the contract and the compiler are
  not mocked; the network and the clock are.
- **Assert on the value and on the error type**, with the expected number's source beside it.
- **Golden files for output you cannot express as an assertion**, regenerated by a documented command.

## The gates

```sh
go build ./...
go vet ./...
gofmt -l .          # must print nothing
go test -race ./...
```

## Review checklist

- [ ] Every goroutine has an exit, and every error is wrapped or returned.
- [ ] `ctx` first and propagated; no `context.Context` in a struct.
- [ ] No package-level mutable state, no init-time I/O.
- [ ] Exported API documented, and adding to it is additive.
- [ ] The test fails if the change is reverted, and runs under `-race`.
